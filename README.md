# Vercel for Herdr

The Vercel layout adapts the Geist typography and hairline borders from [DESIGN.md](DESIGN.md) to Herdr's desktop workspace. It uses a dark palette in both system appearances.

Open the command palette with `Cmd+Shift+P`, search for **Vercel terminal background**, and select **Choose image**. The image fills each terminal pane. The same panel has a **Remove image** button that restores the solid background. The picker uses the original local PNG, JPEG, or WebP file, so keep it in place to continue using it.

To install on another Mac, copy the files under `layouts/`, `themes/`, and `mods/` into their matching folders under `~/.config/herdr-app/`, then select **Vercel** in Herdr's layout picker.
