# Vercel for Herdr

The Vercel layout adapts the Geist typography and hairline borders from [DESIGN.md](DESIGN.md) to Herdr's desktop workspace. It uses a dark palette in both system appearances.

To use an image behind your terminal panes, install the [Terminal background mod](https://github.com/gridness/herdr-mods/tree/main/terminal-background), then open **Terminal background** in the command palette.

To install on another Mac, copy the files under `layouts/` and `themes/` into their matching folders under `~/.config/herdr-app/`, then select **Vercel** in Herdr's layout picker.
